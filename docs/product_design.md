# 1. 产品定位

## 产品名称

ListenPal AI Agent Studio

## 产品定位

面向欧美女性用户的 AI 有声剧内容生产平台。

通过 Agent 工作流完成：

    竞品分析
      ↓
    内容策略生成
      ↓
    故事规划
      ↓
    章节生成
      ↓
    质量评测
      ↓
    Prompt优化
      ↓
    有声剧生成
      ↓
    数据分析

核心目标不是单纯生成小说，而是生产能够进入有声剧链路、通过质量审核并具备用户留存和转化潜力的内容。

------------------------------------------------------------------------

# 2. 项目背景

传统音频短剧生产流程：

    选题
     ↓
    剧本创作
     ↓
    审核修改
     ↓
    配音制作
     ↓
    上线测试

存在：

-   内容生产周期长
-   人工成本高
-   内容质量波动大
-   难以快速验证用户偏好

ListenPal 探索利用 AI Agent
提升内容生产效率，同时通过评测体系保证生成质量。

------------------------------------------------------------------------

# 3. 用户画像

目标用户：

欧美女性音频短剧用户。

核心内容偏好：

-   强人物关系
-   强冲突开篇
-   情绪拉扯
-   身份差异
-   秘密揭露
-   复仇、逆袭等情绪机制

内容特点：

-   节奏快
-   对话自然
-   适合音频播放
-   章节具有 Hook

# 5. 核心模块设计

## Module 1：Content Strategy Agent

输入：

-   用户画像
-   内容题材
-   平台目标

能力：

-   分析竞品爆款内容
-   提取心理钩子
-   分析信息差
-   分析情绪升级机制
-   生成内容 Brief

输出：

    题材方向
    人物关系
    核心冲突
    章节节奏
    情绪曲线

------------------------------------------------------------------------

## Module 2：Story Planning Agent

负责：

-   故事核心冲突设计
-   主角关系设计
-   Chapter Outline生成
-   Story Bible维护

目标：

避免：

-   人物漂移
-   剧情断裂
-   长篇失控

------------------------------------------------------------------------

## Module 3：Story Generation Agent

负责：

-   分章节生成正文
-   控制剧情节奏
-   优化人物对白
-   提升音频化表达

Prompt优化方向：

从：

"不要生成AI味内容"

优化为：

"像真实用户在电话中向朋友讲述故事，使用自然对白推动剧情。"

------------------------------------------------------------------------

# 6. AI质量评测体系

## 文本评测指标

### 1. 剧情质量

检查：

-   剧情逻辑
-   冲突设计
-   情绪升级

### 2. 人物一致性

检查：

-   人物设定
-   人物关系
-   行为合理性

### 3. 章节吸引力

检查：

-   开篇抓人程度
-   Chapter Hook
-   用户继续阅读意愿

### 4. AI生成质量

检查：

-   AI自我暴露
-   中英混杂
-   重复表达
-   文风异常

------------------------------------------------------------------------

# 7. Bad Case优化闭环

    内容生成

    ↓

    质量评测

    ↓

    Bad Case分析

    ↓

    定位问题阶段

    ↓

    Prompt优化

    ↓

    重新生成

    ↓

    效果验证

问题分类：

  问题         优化方向
  ------------ -----------------
  人物漂移     Story Bible优化
  剧情断裂     章节规划优化
  AI味明显     正文Prompt优化
  音频体验差   TTS参数优化
